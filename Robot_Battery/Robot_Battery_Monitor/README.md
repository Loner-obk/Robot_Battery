# Моніторинг акумулятора мобільного робота

Практична робота № 4 з веб-програмування. Односторінковий застосунок на React із REST API на Node.js.

## Можливості

- Моніторинг заряду, напруги, струму, температури та потужності.
- Графіки показників за 5, 15 або 60 хвилин.
- Історія вимірювань, журнал подій та експорт CSV.
- Налаштування порогів попереджень і ємності акумулятора.
- Симуляція низького заряду, перегріву, заряджання та втрати зв’язку.
- Приймання зовнішньої телеметрії через API.

Початкові показники та історія є демонстраційними. Фізичний робот до проєкту не підключений.

## Запуск

Потрібен Node.js 20.19 або новіший. У корені проєкту виконайте:

```sh
npm ci
npm run build
npm start
```

Відкрийте **http://127.0.0.1:3004**. Для зупинки натисніть Ctrl+C.

`npm ci` встановлює залежності, `npm run build` створює клієнт у `dist`, а `npm start` запускає API й обслуговує готовий клієнт. Після зміни клієнтського коду виконайте `npm run build` повторно.

## Розробка

Для автоматичного оновлення клієнта запустіть у першому терміналі:

```sh
npm start
```

В іншому терміналі:

```sh
npm run dev
```

Відкрийте адресу, яку виведе Vite. Запити `/api` спрямовуються на Node.js сервер на порту 3004.

## Тести

```sh
npm test
```

Тести перевіряють розрахунки, пороги, валідацію, симулятор, HTTP API та відновлення збережених даних.

## Структура

```text
src/
  App.jsx                Спільний стан, опитування та маршрути
  main.jsx               Запуск React
  api.js                 HTTP клієнт
  styles.css             Стилі й адаптивність
  components/            Графік та піктограми
  pages/                 Моніторинг, історія, налаштування
server/
  index.js               HTTP сервер, API та збереження
  domain.js              Симуляція, перевірки й розрахунки
tests/
  monitor.test.js         Автоматичні тести
```

## Зовнішня телеметрія

У налаштуваннях виберіть «Зовнішній API робота». Локальний адаптер може передати вимірювання так:

```sh
curl -X POST http://127.0.0.1:3004/api/telemetry \
  -H 'Content-Type: application/json' \
  -d '{"soc":64,"voltage":23.8,"current":2.1,"temperature":34.2}'
```

Додатний струм означає розряджання, від’ємний — заряджання. Сервер фіксує час приймання; після 10 секунд без нових вимірювань дані вважаються застарілими. API слухає `127.0.0.1`, тому для фізичного робота потрібен локальний адаптер.

Панель виконує моніторинг і не замінює захист BMS. Пороги та ємність для фізичного акумулятора потрібно узгодити з його характеристиками.

## Завантаження на GitHub

Завантажте **вміст цієї папки** в корінь свого репозиторію зі збереженням структури. Файли `package.json`, `README.md` та папки `src`, `server`, `tests` мають бути на одному рівні. Додайте також прихований файл `.gitignore`.

`node_modules`, `dist` і `server/data` створюються автоматично та виключені через `.gitignore`. Файл `package-lock.json` залишено для відтворюваного встановлення залежностей. Звіт DOCX і файли перевірки оформлення до репозиторію програми не входять.

Телеметрія та налаштування зберігаються у `server/data/state.json` після першого запуску. Змінні середовища: `PORT` (типово 3004) і `DATA_FILE` (інший файл стану).
